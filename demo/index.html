intelligent-scissors

Click around an object and the outline follows its edges.

Documentation GitHub
Drop the image to trace it

Tracing

Click
Place an anchor
Move
The path follows the edges
Shift
Hold for a straight line where there is no edge
Double-click
Close the shape, or click the first anchor
Backspace
Remove the last anchor
Esc
Discard the shape

Image

Or drop one onto the mat. It stays in your browser.

Brightness / Contrast

This image is 16-bit grayscale. Brightness and contrast change what is shown and also which edges the path finds: more contrast makes faint edges stronger.

Cost function

The cost map shows what the path sees: dark pixels are cheap to walk along. If an edge is not dark there, no weighting will make the path follow it.

Use it in your page

npm install intelligent-scissors 
import { attachScissors } from 'intelligent-scissors/canvas';

attachScissors(canvas, {
  image: img,
  onComplete: polygon => save(polygon),
});
