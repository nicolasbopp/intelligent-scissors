intelligent-scissors

Live-wire segmentation for the browser. Click around an object and the outline follows its edges.

GitHub
Drop an image to trace it

How to use

  • Click place an anchor
  • Move the path follows edges
  • Double-click or click the first anchor to close
  • Backspace undo · Esc cancel
